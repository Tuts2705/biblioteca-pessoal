# Gerenciador de Biblioteca Pessoal

Aluno: Arthur Favaretto

## Descrição
Este projeto consiste em uma aplicação de console desenvolvida em TypeScript para gerenciamento de uma biblioteca pessoal.

O sistema permite cadastrar livros, controlar leituras, realizar buscas e gerar estatísticas da coleção.

## Funcionalidades

- Adicionar livros
- Remover livros
- Buscar por título
- Listar por autor
- Marcar livros como lidos
- Listar livros lidos e pendentes
- Gerar estatísticas da biblioteca
- Classificar livros por década

## Tecnologias utilizadas

- Node.js
- TypeScript

## Como executar o projeto

1. Instale as dependências:
npm install

2. Compile o código:
npm run dev

3. Execute:
node dist/index.js
